# Тренажёр юного астронавта · Junior Astronaut Mission Trainer

Браузерная игра для детей: кадет проходит четыре испытания на борту учебного корабля «Звёздный вихрь», получает звёзды и сертификат.

## Как открыть

Дважды щёлкни `index.html`, или запусти маленький сервер в папке игры:

```
python3 -m http.server 8000
```

и открой http://localhost:8000. Сборка не нужна: обычные HTML, CSS и JavaScript без библиотек.

## Испытания

| # | Испытание | Шаги | Чему учит |
|---|---|---|---|
| 1 | ☄️ Астероидный пояс | брифинг → выбор маршрута (риск и топливо) → пилотирование с радаром траекторий, крупный астероид прямо по курсу | ориентация, скорость, траектория |
| 2 | 🫧 Утечка кислорода | найти отсек датчиком давления → выбрать инструмент → изолировать отсек и восстановить подачу в правильном порядке (кислород всё время убывает) | жизнеобеспечение, ремонт |
| 3 | ☀️ Солнечная буря | сообщение ЦУП и вопрос → выбор укрытия → безопасный режим оборудования → буря и дозиметр (всё на таймере) | космическая погода, радиация |
| 4 | ⚡ Поломка питания | отключить второстепенное (E = P·t, батареи должно хватить на 6 ч) → повернуть солнечную панель к Солнцу → включить системы по приоритету | энергия, логика, приоритеты |

Каждый запуск немного разный: маршруты, место утечки, вид поломки и угол Солнца выбираются случайно.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Страница игры |
| `css/style.css` | Стили. Цвета собраны в `:root` в начале файла |
| `js/core.js` | Ядро: старт, мостик, рамка миссии, итоги, сертификат, звуки, сохранение в `localStorage` |
| `js/missions/*.js` | По файлу на испытание. Новое испытание регистрируется через `Game.register({...})` |
| `assets/img/*.jpg` | Фоны отсеков, сгенерированы в Higgsfield |
