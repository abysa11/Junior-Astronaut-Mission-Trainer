# Тренажёр юного астронавта · Junior Astronaut Mission Trainer

Браузерная игра для детей: кадет проходит четыре испытания на борту учебного корабля «Звёздный вихрь», получает звёзды и сертификат.

## Как открыть

Дважды щёлкни `index.html`, или запусти маленький сервер в папке игры:

```
python3 -m http.server 8000
```

и открой http://localhost:8000. Сборка не нужна: обычные HTML, CSS и JavaScript. Только финальное испытание использует библиотеку **Three.js** для 3D: она загружается из интернета (jsDelivr) при запуске, поэтому для финала нужен интернет.

## Испытания

| # | Испытание | Шаги | Чему учит |
|---|---|---|---|
| 1 | ☄️ Астероидный пояс | брифинг → выбор маршрута (риск и топливо) → пилотирование с радаром траекторий, крупный астероид прямо по курсу | ориентация, скорость, траектория |
| 2 | 🫧 Утечка кислорода | найти отсек датчиком давления → выбрать инструмент → изолировать отсек и восстановить подачу в правильном порядке (кислород всё время убывает) | жизнеобеспечение, ремонт |
| 3 | ☀️ Солнечная буря | сообщение ЦУП и вопрос → выбор укрытия → безопасный режим оборудования → буря и дозиметр (всё на таймере) | космическая погода, радиация |
| 4 | ⚡ Поломка питания | отключить второстепенное (E = P·t, батареи должно хватить на 6 ч) → повернуть солнечную панель к Солнцу → включить системы по приоритету | энергия, логика, приоритеты |
| 5 | 🛬 Мягкая посадка | выбор Луны или Марса → посадка модуля: двигатель против гравитации, наклон, топливо | гравитация, скорость, топливо |
| 6 | 🔴 Финал: Последний шанс на Марсе | корабль сломался на Марсе → **10 солов на станции в 3D**: полив теплицы с расчётом литров, расчёт энергии на ночь, пыль на панелях (мыть водой или беречь воду и связь), поломки и запчасти, инструкции с Земли → 5 шагов ремонта с вычислениями → взлёт | выживание, расчёты, энергия, планирование |

Каждый запуск немного разный: маршруты, место утечки, вид поломки и угол Солнца выбираются случайно.

## Языки

Игра на двух языках: русском и английском. Переключатель **RU / EN** есть на стартовом экране, на мостике и на сертификате, выбор сохраняется в браузере. При первом запуске язык берётся из настроек браузера.

Все тексты написаны прямо в коде как `L('по-русски', 'in English')`.

## Управление

- **Компьютер:** стрелки или `W A S D`, либо мышкой по полю; скорость — кнопки или `1 2 3`.
- **Телефон и планшет:** под игровым полем появляется джойстик-кружок. Палец можно поставить в любую точку зоны джойстика: кружок встанет под палец, а ручка покажет направление и силу движения. Справа — кнопки скорости.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Страница игры |
| `css/style.css` | Стили. Цвета собраны в `:root` в начале файла |
| `js/core.js` | Ядро: старт, мостик, рамка миссии, итоги, сертификат, звуки, сохранение в `localStorage` |
| `js/missions/*.js` | По файлу на испытание. Новое испытание регистрируется через `Game.register({...})` |
| `assets/img/*.jpg` | Фоны отсеков, сгенерированы в Higgsfield |
| `assets/base/*` | Базы на Луне и Марсе, иконки модулей, посадочный модуль (Higgsfield) |
| `assets/mars/*` | Сцены, небо, текстуры и предметы для марсианского финала (Higgsfield, Gemini Nano Banana) |
| `assets/sprites/*.png` | Логотип, ракета, астероиды, станция, робот ЦУП, инструменты и другие картинки из Higgsfield |
